AI Sentiment Analyzer

My first AI/ML porject, built using Python and pretrained DistilBERT Transformer model.

About the Project

This application analyzes user enter text and predicts whether the sentiment of the text is positive or negative.

It runs directly in the terminal and uses pretrained model from Hugging Face.

Tech Stack
python 3.12
PyTorch
Hugging Face Transformer
DistilBERT

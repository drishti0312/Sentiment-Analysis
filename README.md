# AI Sentiment Analyzer

My first AI/ML project, built using Python and a pretrained DistilBERT Transformer model.

## About the Project

This application analyzes user-entered text and predicts whether the sentiment of the text is positive or negative.

It runs directly in the terminal and uses a pretrained model from Hugging Face.

# Streamlit Web Application
This project includes an intractive web interface built using Streamlit.

## Features
- Enter text and analyze it's sentiment.
- View positive or negative prediction.
- See model confidence scores.
- Run the application locally without paid APIs.

## Run the Web Application
 - python -m streamlit run web_app.py

## Tech Stack
1. python 3.12
2. PyTorch
3. Hugging Face Transformer
4. DistilBERT
